# Medieval Village models

The `aldoria-medieval-village.glb` bundle contains selected and modified models
from **Medieval Village MegaKit [Standard]** by Quaternius:

- `Wall_Plaster_Straight`
- `Wall_Plaster_Door_Flat`
- `Wall_Plaster_Window_Wide_Flat`
- `WindowShutters_Wide_Flat_Closed`
- `WindowShutters_Wide_Flat_Open`
- `Door_1_Flat`

Source: https://quaternius.com/packs/medievalvillagemegakit.html

License: CC0 1.0 Universal / Public Domain Dedication
https://creativecommons.org/publicdomain/zero/1.0/

The source glTF models were merged into one GLB and their textures were resized
from 2048 px to 512 px for web delivery. Models by Quaternius.
