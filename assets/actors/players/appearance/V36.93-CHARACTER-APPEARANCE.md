# V36.93 Character Appearance Composer

The local player is now composed from independent synchronized actor parts:

- body: 2 variants
- head: 3 variants
- face: 3 variants
- hair: 4 variants
- facial hair: none + 2 variants
- torso/base clothing: 3 variants
- legs/base clothing: 3 variants
- feet/base clothing: 2 variants

Color channels are independent palette IDs for:
- skin
- hair
- torso
- legs
- feet

All parts share the existing player Idle/Walk/Attack/Hit/Death/Cast/Use
animation contract in all eight directions.

V36.93 is the rendering/data foundation. The old outfit value is used only as a
temporary migration preset until V36.94 exposes direct customization UI.
Equipment from V36.90 remains layered above the appearance composer.
