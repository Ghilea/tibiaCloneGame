# Aldoria Creature Crafted Equipment v7

Requires Creature Products v6.

## New secondary professions
- Smithing
- Leatherworking

You can still choose at most two secondary professions.

## Profession tools
- Smith Tongs -> Smithing tool slot
- Skinning Knife -> Leatherworking tool slot

Smithing and Leatherworking recipes require the matching tool to be equipped.

## New equipment
- Rat Pelt Cap
- Mireweave Cloak
- Skulker Scale Vest
- Fenhide Leggings
- Fenhide Boots
- Cryptbone Buckler
- Warden Plate Helmet
- Warden Plate Armor
- Warden Plate Shield
- Stalker Claw Blade
- Fenbone Maul
- Reed Sinew Bow
- Acolyte Focus Amulet
- Warden Core Hammer

## Defense
Equipment can now have a data-driven defense value.
Every four equipped defense points reduce incoming creature damage by one.
Creature attacks always deal at least one damage.

Existing armor and shields are assigned sensible starter defense values too.

## Install
From the repository root:

    .\INSTALL_ALDORIA_CREATURE_CRAFTING_V7.cmd --dry-run
    .\INSTALL_ALDORIA_CREATURE_CRAFTING_V7.cmd
