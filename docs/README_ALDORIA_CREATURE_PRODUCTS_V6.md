# Aldoria Creature Products v6

Adds a creature-product economy and expands the existing generic crafting system.

## Creature products
Castle Rat: Rat Tail, Rat Pelt
Mireling: Mire Gland, Mire Spore Cluster
Mire Skulker: Skulker Venom Sac, Skulker Scale
Reed Stalker: Reed Sinew, Stalker Claw
Fen Brute: Fen Brute Hide, Fen Brute Bone
Crypt Guard: Crypt Bone Shard, Grave Dust
Bone Acolyte: Acolyte Focus Shard, Grave Dust
Cellar Warden: Warden Core, Warden Plate Fragment

## New recipes
- Brew Mire Recovery Tonic (Alchemy)
- Distill Purifying Tonic (Alchemy)
- Fletch Sinew Arrows (Fletching)
- Cook Fen Marrow Stew (Cooking)
- Carve Bone Fishhooks (Fishing)
- Brew Graveward Tonic (Alchemy)
- Brew Focus Draught (Alchemy)
- Bind Warden Glow Charm (Alchemy)

Orin teaches these recipes. Secondary-profession crafting now advances and persists the matching profession skill.

## Install
Run from the project root:

    .\INSTALL_ALDORIA_CREATURE_PRODUCTS_V6.cmd --dry-run
    .\INSTALL_ALDORIA_CREATURE_PRODUCTS_V6.cmd
