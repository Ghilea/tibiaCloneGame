## Install
Run from the repository root in PowerShell:

    .\INSTALL_ALDORIA_ITEM_RESTYLE_V3.cmd

or dry-run:

    .\INSTALL_ALDORIA_ITEM_RESTYLE_V3.cmd --dry-run
